# Aneural causal specificity: reproducibility archive v18

**Status:** Public versioned GitHub branch. No Zenodo DOI or immutable release has been minted. This archive contains code and summary outputs, not new biological observations. The pre-existing *Stentor* prospective registration on the separate branch remains unchanged.

## Reproduce the principal synthetic result

Requires Python 3.10+ and packages in `requirements.txt`.

```bash
python -m pip install -r aneural_reproducibility_v18/requirements.txt
cd aneural_reproducibility_v18
python Supplementary_Code_6.py --locked Prospective_Stentor_Validation_Analysis.py --outdir audit
python Supplementary_Code_7.py --outdir causal
```

`Supplementary_Code_6.py` checks that the frozen script SHA-256 equals `7b319877eb749736c51fc302637cd0dc49cdc1b460310a3354b5955d96701151` and refuses to run on a modified file. Expected summaries are `ExtendedData_Table8_common_driver_gates.csv` and `ExtendedData_Table9b_intervention_assurance.csv`. Use exact original CSVs here, not the Files system's auto-parsed preview.

`independent_recheck.py` is a separately written arithmetic audit: it computes waveform effective dimensionality via SVD, independently checks the Gaussian observational-equivalence covariance, and evaluates exact four-day sign-flip inference. It expects the trajectories created above in a folder named `audit` alongside `independent_recheck.py`. When run from this directory, use `--` no flags, and `audit/` must contain `common_driver/` and `no_change/` as generated by Code 6.

## Key limitations

- Software pass/fail under a four-day **synthetic** design demonstrates a particular model-class misspecification, not an experimentally measured consciousness marker.
- The frozen **cell-level** primary and held-out model P values cannot be interpreted as four independent days' exact-test evidence. Exact day-level, two-sided sign-flip P=0.125 for the common-driver geometry contrast.
- No real Stentor mechanical/electrical prospective study was executed. No unobserved Rajan untreated RNA recovery controls were inferred or generated.
- Historical codes 1–3, 5, and 16 are bundled for provenance and were not all rerun independently in the v18 verification.
- Doan et al. behavioural source data are third-party data and should be downloaded from their source repository, not relabelled as new recordings.
