OUD–EGR1 reproducibility code snapshot, October 2026

This is a **code-only archival snapshot candidate** accompanying a secondary analysis of public opioid-related transcriptomics. It is not a journal manuscript, peer-reviewed result, institutional ethics determination, approved authorship statement, or DOI-backed scientific repository.

Research sources: GSE174409 (paired human DLPFC/NAc; 40 unique donors), GSE182321 (independent human BA9), GSE198121 (small living-participant peripheral-blood cohort), and published Carter et al. 2026 supplementary tables. Raw data are available from their original public repositories; no subject-level protected sequencing reads are redistributed by this code release.

Main completed sensitivity: DLPFC EGR1 edgeR model q=0.0269 in the complete study; 40/40 leave-one-donor-out effects negative but only 37/40 retaining genome-wide q<0.05. BA9 does not validate EGR1 at q<0.05. HLA and MTRNR2L12 interaction calls are exploratory. There is no prospective causal or allele-aware patient-specific validation.

Scripts and notebooks in release are as-is research tools; run them against public source files and verify provenance, software versions, and checksums. Full data tables and manuscript are not bundled in this GitHub code-only tag. No originality, author approval, COI, funding, ethics or publication status is implied.
