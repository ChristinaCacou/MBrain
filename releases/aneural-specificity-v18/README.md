# Shared physiological drive can mimic cross-modal integration | consolidated v18

**Status:** exploratory computational/theoretical analysis with secondary biological reanalysis; NOT experimental proof of consciousness; NOT a completed preregistered wet-lab trial.

## Core results and reproduction
1. Install Python 3.11+ packages from `requirements.txt` in an isolated environment.
2. Run `python code/Supplementary_Code_6.py --locked code/Locked_Prospective_Stentor_Validation_Analysis.py --outdir work/central`. The script verifies the SHA-256 of the original locked analysis (`7b319877eb749736c51fc302637cd0dc49cdc1b460310a3354b5955d96701151`). Outputs are 96 synthetic cells over four simulated recording days. **The synthetic model, although designed to violate directed intermodal transfer, passes three frozen statistical gates.**
3. Run `python code/Supplementary_Code_7.py --outdir work/causal`. This generates three causal scenarios with 4,000 simulated campaigns each, 12 simulated day clusters per campaign.
4. To reproduce the biological adaptation estimates from the original author-released CSV, use `python code/Supplementary_Code_16_source_reproducer.py --help` to inspect source fetch instructions and compare against `results/ExtendedData_Table13*`. Source is https://github.com/nhithuydoan/associative_learning_Stentor/blob/main/data/dataset_followup_2.csv (Git blob `04e271fab29e9f826f7d3a9dca9c4e9040c1dbfc`). **The original video-derived recordings were generated by Doan et al., not by this release.**
5. The old computational explorations are preserved as individual historically named code files. They are provided for auditing, not as additional confirmatory independent experiments.

This checks deterministic software reproduction, NOT biological validation or independent implementation of every estimator.

## Known limits
The locked pipeline uses cell-level tests and cluster bootstrap intervals from four simulated days. Those are not verified biological Type I error tests with independent-day randomization. The exact sign-flip test over four independent day summaries cannot have a two-sided p-value below 0.125. No simulated result should be interpreted as direct evidence about phenomenal consciousness. The Stentor RNA reanalysis uses previously published processed estimates; six untreated time controls from the original sequencing archive were unavailable for the time-adjusted contrast.
